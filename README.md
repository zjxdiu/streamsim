## What is this?

Streamsim is originally a [Websim project](https://websim.ai/@stackingbooks/streamsim). It's one of the most popular project on the platform.

It is basically a streamer simulator, but it sends your actual screenshots to a vLLM (Vision Large Language Model) and ask AI to generate some chat messages, so it feels like you're streaming and get viewer chats, but it's all AI-generated content.

A huge shoutout to author [@stackingbooks](https://websim.com/@stackingbooks).
